## GoMami 是什么，产品线怎么分

GoMami Networks, LLC 是一家只做中国大陆优化方向的 VPS 商，官网口号是 “The Fastest China Route. The Strongest Performance.”，节点覆盖香港、日本、新加坡三个地区。第三方测评常把它和 Sharon Networks 联系在一起，官网自己没写这层关系，当背景信息听就行。

真正要搞清楚的是几条产品线的差别，因为这直接决定多花的钱买到了什么：

- **HKG Turin**：AMD EPYC 9575F（Zen 5，最高 5.0GHz），旗舰线。2–5Gbps 端口，100GB 起 NVMe。建站、数据库、单核敏感业务选这条。
- **HKG Peak X5**：AMD Ryzen 9 9950X，加速频率最高 5.7GHz，是这几颗 CPU 里单核频率最高的一颗。适合游戏服务器、编译、高并发。

- **HKG Forge**：EPYC 7663，56 核 112 线程，128GB / 256GB 内存，960GB–4TB NVMe，10–20TB 流量。给大内存、大流量业务准备的，普通建站不用看。
- **JPN Pulse / SIN Pulse**：日本和新加坡各五个档位，两条线彼此配置和价格几乎一致，$29–$338 区间，比香港 Pulse 的 $49–$499 便宜一截，同样走三网优化。

所有套餐默认带 “China Mainland Optimized Pro”，官方标注大陆 RTT 低于 50ms，DDoS 清洗能力最高 600Gbps。三网优化是标配，不用额外加钱买单。

## 实测数据：跑分、磁盘与三网带宽到什么水平

先看硬件。香港 Turin Mini 只有 2 核，用的是 EPYC 9575F 服务器芯片，第三方在 2025 年底测到的 Geekbench 5 是单核 2259、多核 4262；另一组同机型测试为单核 2495、多核 4905，差异大概来自测试环境和调度。SysBench 单核 6173、多核 12310。Geekbench 6 的转述数据是单核 2892、多核 5223——五和六不是一套评分体系，看量级就好。

磁盘更值得看。fio 混合读写 4K 总计 1.33 GB/s（333.7k IOPS），1M 块总计 8.03 GB/s。同门的 HKG Pulse Mini 用 EPYC 7763，4K 总计 660.83 MB/s、1M 总计 2.49 GB/s，差了将近一倍。跑数据库或大量小文件读写的话，这个差距比 CPU 跑分更影响日常体验。

网络路由结构：电信去程 163/CN2、回程 CN2；联通去程 4837、回程 9929；移动去程 CMI、回程 CMIN2。三家各走各的优化路径。

## 那个没人爱提的短板：移动上行

移动用户是 GoMami 最需要谨慎对待的一群人。下行能跑到 550–933Mbps，上行却稳定卡在 30–60Mbps，多个测试点还伴随断流。

具体数字：广东移动 1Gbps 拉到 HKG Turin，上行 37–66Mbps，中间多次出现 0 字节；武汉移动上行 33–37Mbps，下行 550Mbps；宁波移动上行 37–41Mbps，下行 653Mbps；另有一条移动线路下行跑到 933Mbps，上行只有 35Mbps。日本节点情况类似，广东移动上行 35–37Mbps。

这意味着什么：从服务器下载东西、看视频、拉文件，体验很好；往服务器上传——直播推流、备份大文件、做反向代理转发上传流量——会很难受。

有第三方测评还提到，GoMami 的 DDoS 防御策略比较主动，有时会限制上行带宽，做反向代理的机器可能受影响。这条只有第三方说法，官方文档没写，但和上面的实测现象能对上。

选择逻辑因此很清楚：电信、联通用户随便挑地区，香港优先；移动用户如果只是下载为主，香港和日本都行，纯看移动网络表现新加坡在测评里评价更好；移动上行是刚需的，别硬上。

- 网站或业务用户在中国大陆，对延迟和稳定性敏感，预算落在 Pulse Mini（$59）到 Turin Air（$129）这一档

## 常见问题

**GoMami 的三网优化是真的还是营销词？**

是真的，而且实测能验证。电信回程 CN2、联通回程 9929、移动回程 CMIN2，是三条不同的路径，不是同一根线换个说法。测评里电信和联通单线程都能跑到 500Mbps 以上。

**香港、日本、新加坡怎么选？**

电信用户香港约等于日本，都好过新加坡；联通用户香港最优；移动用户如果只看下载，新加坡在测评里评价最高，香港和日本次之。建站和业务用途三个地区都够用，香港硬件选择最多，优先香港。

**Turin 和 Peak X5 差在哪？**

CPU 不同：Turin 用 EPYC 9575F（Zen 5，最高 5.0GHz），Peak X5 用 Ryzen 9 9950X（最高 5.7GHz），后者单核频率更高。端口起点都是 2Gbps，Pro 档都到 5Gbps。价格上 Peak X5 便宜一档，Mini 是 $59 对 $69。磁盘这块没有公开的 Peak X5 实测数据，只有第三方测评称它的磁盘 IO 相比 7763 系列被限制、大约砍半，而 CPU 跑分是满血 9950X 水平——这条仅作参考，官网没有相关说明。要 IO 稳就选 Turin，要最高单核频率就选 Peak X5。

**买了不满意能退吗？**

激活后 24 小时内可以全额退款，限新购、每用户一次，续费不适用。退款后数据立即永久删除。拿它当试用期用是可行的，但别拖过 24 小时。

**流量超了会怎样？**

普通套餐会被限速，具体阈值官方没写死；Forge 系列按 $0.06/GB 计费。想避免麻烦就提前买流量包，或者直接升档——长期流量吃紧的话升档比反复买包划算。
